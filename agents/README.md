# AI Agents Architecture (Planned)

This directory is reserved for multi-agent workflows and orchestration for mac OS.

## Planned Agents:
1. **Resume & Profile Analyzer**: Extracts structured skills, evidence, education, and experience from user input/resumes.
2. **Market Requirements & Trajectory Researcher**: Analyzes industry requirements, job postings, and career trajectories of professionals in the target role.
3. **Gap Analysis Engine**: Compares the user's current capabilities and evidence against target role expectations.
4. **Pathway Generator**: Formulates the personalized 4-stage action plan (`LEARN` → `BUILD` → `DEMONSTRATE` → `REASSESS`).
5. **Ask mac OS (Conversational Interface)**: Context-aware interactive assistant guiding the user along their pathway.

> Note: Implementation will begin in subsequent development phases.
